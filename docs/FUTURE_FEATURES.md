## 2. Feature Specifications

### 2.1 Contextual Query Rewriter
Transforms ambiguous user follow-up questions using conversation history before performing RAG search.

#### Example:
- **Turn 1**: User: *"Tell me about mobile app development services."*
- **Turn 2**: User: *"What are the pricing options?"*
- **Rewritten Query**: *"What are the pricing options for mobile app development services at Mobiloitte?"*

---

### 2.2 Hybrid Search & Cross-Encoder Reranking

Combines Sparse BM25 Keyword Search with Dense Vector Embedding Search, then re-scores results using a Cross-Encoder model.

```text
Query ──┬──► BM25 (Keyword exact match) ──► Top 20 Candidates ──┐
        │                                                       ├──► Cross-Encoder Reranker ──► Top 3 Context Chunks
        └──► Vector Search (Semantic) ────► Top 20 Candidates ──┘
```

---

### 2.3 Citation & Source Attribution Engine

Appends clickable, verifiable source metadata to generated responses.

#### Generated Output Example:
> *"Mobiloitte provides native iOS and Android application development services with dedicated QA testing..."*
>
> 📁 **Sources Referenced:**
> 1. [Company_Overview_2026.pdf (Page 4, Section 2.1)](file:///docs/Company_Overview_2026.pdf#page=4)
> 2. [Services_Catalog.docx (Section 3.4)](file:///docs/Services_Catalog.docx)

---

### 2.4 Hallucination Detection & NLI Verification

Uses Natural Language Inference (NLI) to ensure every claim generated by the LLM is logically entailed by the retrieved source context chunks. If entailment score is below `0.75`, the response is automatically flagged and replaced with a verified fallback.

---

### 2.5 Multi-Agent Tool Calling (ReAct Framework)

Enables the AI Assistant to autonomously execute actions by invoking registered tools:

```json
{
  "tool": "check_project_status",
  "arguments": {
    "project_id": "MOB-9942",
    "include_milestones": true
  }
}
```

---

### 2.6 Voice Support (STT / TTS) & Multimodal Image Understanding

- **Speech-to-Text (STT)**: OpenAI Whisper microservice streaming user speech input.
- **Text-to-Speech (TTS)**: ElevenLabs / Web Speech API streaming synthesized voice responses.
- **Multimodal Image Input**: User uploads architecture diagrams or UI screenshots for visual analysis.
